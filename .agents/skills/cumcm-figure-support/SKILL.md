# 代码生图与图文衔接

先读 [授权](../../../workflow/rules/governance.md)、[聊天](../../../workflow/rules/chat.md) 和 [代码生图与图登记](../../../workflow/rules/evidence.md#代码生图与图登记)，核对当前项目、状态、来源版本及已获授权的绘图范围。直接调用也执行入口检查；材料位置不明确时先查现有记录，不猜项目。

本 Skill 服务现有 G0、G2、每问 B/D 的图表规划和论文整合，不增加阶段或确认点。它只使用已经存在的研究内容：不新增实验、改模型、发明数据或结论，不自动做灵敏度、风险场景或消融。发现缺证据，标明“研究未做”并交回主执行者；是否补做由用户决定。重绘已有结果不等于授权复跑研究。

## 总体图的默认含义

“总体框架图、建模框架图、总体模型图”默认画模型结构：核心数学模型及变量、目标、约束、计算关系居中，三问表现为共享骨架与各问 Model Delta。仅明确要求流程图时选择对应流程型图。按 [模型图方法](references/code-figure-guide.md#总体模型图的结构与信息预算) 执行参数连到作用组件、短框预算、语义保真与渲染后的 10～20 秒可读性检查。

## 从研究内容到可交接的图

1. **明确读图任务。** 对照相应阶段的报告、验证结果或已确认结构，说明读者需要理解什么。精确数值优先表；多类别 × 季次 × 适配规则的长列主动比较条件表、矩阵、时间格图与代码结构图，避免正文逐格重复。趋势、差异、关系、结构和流程才考虑图。没有阅读作用就不画，不为填页增加装饰图。按 [代码生图指南](references/code-figure-guide.md) 选择表达方式和验收重点。
2. **先核对来源与逻辑。** 数据图锁定实际输入、单位、对象、比较口径和来源版本；统计汇总也须有源码并遵守既有研究口径。总体模型图优先读取已确认共享骨架、每问 report.md 的 Model Delta、真实参数作用关系及边界；核对节点、组件、边语义与当前来源版本后才编码，不从候选/运行日志猜。材料不足先查来源并交回研究方补交接，不能编关系。G0 仅有题意时按共享规则交有依据的“建模要素草图”或缺项，不默认画步骤链，也不提前指定未选模型；用户只要文字时保持范围，不额外生成图或追加审批。逻辑有新歧义则交回原研究确认点，不在排版中决定研究路线。
3. **按类型编码。** 数据、EDA、结果和真实验证图优先 Python/matplotlib；关系网络可用 NetworkX/Graphviz；框架、算法或模型结构优先 Graphviz/TikZ。Mermaid 仅作逻辑草图和结构确认。所有正式论文图必须有源码、输入数据或结构定义及可复现命令，禁止文生图、生成式图像模型、AI 直接绘制最终框架图和无法由源码重建的手工最终图。
4. **渲染并验收。** 保存代码、输入引用和版本、环境/字体、运行命令、输出位置；优先矢量 PDF，并按需导出清晰预览。全图文字为黑色，颜色只用于有意义的数据编码。检查实际渲染图，再检查论文最终 PDF 中的尺寸、裁切、字号、单位、图注和正文引用；总体模型图还按指南检查视觉中心、框内信息预算、语义及 10～20 秒内能否识别模型关系；不通过时重组结构，不缩字硬塞。渲染成功不等于验收通过。没有渲染、快读或嵌入页检查能力时分别标明未检查，不冒称真实读者已计时通过。
5. **登记和交接。** 项目内 `paper_evidence/figure_registry.md` 是唯一轻量图索引，字段沿用 [记录模板](../../../workflow/templates/records.md)。独立支持者交回登记条目，由主执行者按共享规则合并，避免并发写同一索引。每个候选图交接 Why（图前目的）、What（展示对象、单位和范围）、So What（图后真实发现）、Then What（对理解、建模或结论的作用）及结论边界。只帮助理解的图可明确没有改变模型选择，不虚构作用。Paper Builder 从登记表组织正文/附录，报告仅引用 Figure ID，不复制另一套图卡。

总体模型图排除试跑、热启动、候选编号、M0/M1/N10、挑战者、留出、替换门槛、预注册、冻结、审批、Reviewer、state、workflow、run id 等过程噪声。若某内容确是必要数学机制，用准确可读的机制名称表达并给依据；“收益—管理复杂度权衡”可以保留，不能借例外保留整条选型流程。边界放相关组件旁注/图注，不能做“综合结果→解释边界”的末端步骤。

**题注与编号**：正式论文图题注由排版自动编号，禁止手写“图1/图2”再叠加自动编号造成“图1 图1”；禁止把内部 Figure ID 印进正式题注或图内大字。图内文字黑色；颜色仅用于有信息的数据编码。

## 交付边界

- 交回候选图、完整生成材料、复现命令、登记条目、图文建议和已做/未做的验收；图源变化时标记受影响的图和章节待复核，保留旧版本，不覆盖冻结快照。
- 不写正式 `state.json`、不修改阶段或冻结状态。作为独立支持者，将来源问题、阻塞及绘图活动交主执行者登记；由主执行者汇入共享账本和 AI 使用日志，不把 AI 自检写成人工核验。
- 已验证的反例、负面结果或不稳定性同样可以成图；不得通过裁切、遗漏分组或挑选有利情景隐藏会改变结论的证据。若真实验证没有视觉收益，用正文或表格即可。
