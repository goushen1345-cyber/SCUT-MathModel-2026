# 题目与数据

先完整读取 [授权](../../../workflow/rules/governance.md)、[聊天](../../../workflow/rules/chat.md)、[证据](../../../workflow/rules/evidence.md)、[状态](../../../workflow/rules/state.md)。读取当前项目状态和本阶段批准依据；直接调用本 Skill 也不能跳过总控权限检查。

## 理解全题

阅读全部题面与附件，逐问建立“要求的输出—证据位置—未知口径—依赖”。区分事实、假设与建议；识别 CORE 的理由、共享参数和建议顺序。输出一份全局 report.md 和依赖图，通俗解释后停在 G0。未确认歧义不擅自解释为方便求解的口径。

## 数据方案

G0 批准后盘点文件、工作表、行粒度、主键、单位和关联。审计格式、缺失、重复、极值、时序/分组泄漏与模板空位；分清未观测、结构性空缺、真实零。原始材料只读。

EDA 图可以帮助认识数据结构、说明处理、支持建模判断或验证结论；解释为何画、真实发现、证据强弱和实际用途，不强称每张图都改变模型。异常算法只标记候选，不证明录入错误；不默认标准化、删极值或补零。

为每项处理记录源位置、证据、候选、影响、推荐和可逆性。将语义处理及必要机械处理组成明确批次，讲解后停在 G1；无处理需求也明确说明并确认该口径。

## 执行与冻结

G1 获批后只在候选副本执行列明处理，保留原值、源行/合并区域、变换日志与前后数量/分布影响。预处理拟合属于模型训练流程的，留在训练折内，不在全数据提前拟合。

独立核验主键、单位、关联、守恒/业务条件及批准范围，更新证据与 AI 记录；停在 G2 请求冻结指定数据版本。新增问题不得夹入批准批次。

全局初始化一次，但允许人工批准的回访。改冻结口径先报告受影响的实验、小问和论文主张，再请求重开；不覆盖旧版。不得自动启动 Q1，须有进入授权。

## 专业参照与阶段交付

理解题目时读 [数据高手指南](references/expert-problem-data.md) 的“题意与结构”；审计、探索和处理时读其对应部分；准备 G2 时读“图表与交接”。阶段开始在聊天说明质量目标。写作接口遵循 [证据规则](../../../workflow/rules/evidence.md#阶段交接与写作)，交付字段用 [现有记录模板](../../../workflow/templates/records.md)。

G0 前的全局 report.md 说明现实矛盾、各问决策/输出、难点、事实与假设、共享条件和 CORE 理由。G0 确认后，可在已有写作范围内据此起草前置章节；按 [数据指南的写作交接](references/expert-problem-data.md#前置材料怎样交给写作方) 分开任务条件、难点/建模要求与跨问关系，内部歧义和待核项完整保留，不原样复制成论文待办。初步路线不能写成已选模型。**交给 Paper Builder 的正文须遵守人话书面语与边界密度规则**（见论文写作指南），聊天教学中的反复提醒不要原样贴进重述/分析。

数据主报告分清质量审计、探索发现和未观测信息假设。既给实际处理摘要，也给保留原值的理由；把真实发现连到图表、单位、来源、解释边界和可能的模型作用，不只交统计表。G2 前在同一确认点核对数据可靠性与写作材料完整性；表达不足先补解释，不自动重跑或新增处理。

G2 确认指定版本后交出可写数据章的材料：来源与结构、处理事实和理由、关键探索发现、图表正文说明、待补项及证据版本。章节可由同一 Paper Builder 起草或交组员写作；不另建平行研究报告，不以数据章已写为由启动 Q1。

## 阶段图表规划

G0 后按 [图型与成熟度规则](../../../workflow/rules/evidence.md#代码生图与图登记) 判断总体图：默认面向模型结构，当前仅有题意时交已确认决策对象、目标含义、约束与参数作用关系的建模要素草图，不提前定变量或算法。材料不足列缺项并回研究方，不能默认画成任务步骤链；明确要研究流程才画流程。后续由单问研究交共享骨架与 Model Delta。遵循已有写作/绘图授权与只交文字等限制，不另增图形关口。多类别、多季次和一对多适配长列同时判断是否用条件表、矩阵或时间格图承载细目，正文只解释关键含义。G2 后将数据候选图分为正文、附录/支撑、内部检查，写入 [图登记规则](../../../workflow/rules/evidence.md#代码生图与图登记) 指定的单一 registry；纯精确数值展示优先考虑表。

需要代码制图时按已确认数据与结构调用 [figure-support](../cumcm-figure-support/SKILL.md)。数据研究方负责真实发现、解释和边界，Figure 只处理表达与复现；没有分析证据不得让它创造发现、参数扫描或风险情景。
