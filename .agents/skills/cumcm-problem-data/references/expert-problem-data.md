# 题意、数据探索与写作交接高手指南

按阶段读：G0 前读“题意与结构”，交接/前置写作时读“前置材料怎样交给写作方”；G1 前读“审计与探索”“处理选择”；G2 前读“图表与交接”“验收”。目的不是多画图，而是让团队和读者理解数据为何可靠、问题有什么结构、建模判断凭什么成立。

## 题意与结构

先把每问翻译为可核对的任务：对谁、在什么时间范围、用哪些已知信息、作什么决策或推断、输出什么、受哪些要求限制。区分原文要求、附件观察、团队假设与建议；对关键原句保留位置。

问题分析说明现实矛盾及三问等各问的递进，不只改写题面。例如农业优化要解释：单位收益较高不代表可以无限扩大种植，因为面积、适种、季次、销量和轮作共同约束决策。**该农业例子仅作分析角度示例，非所有 C 题默认模板**；不能在读题前假定本题都有这些条件。
G0 交付的总体思路是待验证路线：哪些因素共享、哪问依赖哪问的什么输出、CORE 为什么值得深入。未获当前问研究许可时，只做全局结构分析，不借“写问题分析”启动后续问建模。

## 前置材料怎样交给写作方

全局 report.md 继续完整记录未知、歧义、核验计划、风险和证据不足；聊天继续教用户理解和作决定。给 Paper Builder 的是同一事实的可写范围及来源，不能要求研究方先删除“待核验”来改善论文语言。表达分层遵循 [证据规则](../../../../workflow/rules/evidence.md#三种表达层)。

在既有交接区按用途定位：题目对象、已知条件、约束和输出交问题重述；困难为何使简单处理失效及其要求的模型能力交问题分析；共享基础、逐问新增与真实依赖交总体思路；内部排程与待核事项保持原记录。具体编辑方法和正反例只维护在 [论文转换指南](../../cumcm-paper-builder/references/expert-paper-writing.md#前置章节的论文转换)。

例如题面明确跨三年轮作时，可从此推出“多年决策需要联动描述”；覆盖方式有歧义则保留歧义及影响，不能直接定成某条逐地块约束。销售上限待核时，可交接“正常销售和超额部分经济含义不同”的建模要求，不能把产量记录转成已知需求。提出能力要求不选择算法，不启动下一阶段研究。

地类、季次、适种规则构成长列时，按原题来源整理维度、例外和待确认格；判断条件表/关系矩阵/时间格图是否比长段清楚。不新增统计、不补未知适配关系；表格保留细目，交给正文的是关键含义。G0 总体图默认按模型要素组织已确认的决策对象、目标含义、约束与参数作用，材料不足只交缺项/有据草图，不改画步骤链；明确要研究流程时才画相应流程。不借旧下游产物补“最终模型”，不在题意阶段替各问生成已完成 Model Delta。

交接检查：条件是否完整且没有掺入解释性重复？每个主要困难能否推进到有依据的建模要求？总体关系是否新增跨问认识？每个未知及影响能否在原报告找到，必要边界是否进入对应主张？检查和修正放原交接区，不再建前置研究报告。

## 审计与探索是两项不同工作

| 问题 | 通常怎样做 | 适用条件与边界 |
|---|---|---|
| 数据可靠吗 | 盘点文件/表、行粒度、主键、类型、单位、重复、空缺、异常组合及关联覆盖 | 按字段语义解释；表格合并单元格的空白不自动等于缺失观测 |
| 数据是什么结构 | 查看分布、类别规模、分组差异、时间结构和观测覆盖 | 结合问题选取；汇总均值不能掩盖组间不同或时间变化 |
| 哪些差异值得建模 | 围绕实际输出比较数量、比例、成本收益、误差或资源瓶颈 | 派生指标说明公式、单位和分母；没有真实销量不能把产量当销量事实 |
| 发现如何影响判断 | 说明约束、特征、评价协议或假设为何这样设计，也可仅帮助认识结构 | 描述性图有价值；相关性不等于因果、样本规律不必外推 |

先列与题意有关的分析问题，再选统计和图。不要把 describe、缺失率、相关热图的默认输出当完成标准。即使数据没有缺失，也应探索会影响目标或理解的结构；如果数据不足以支持某项分析，说明缺什么及影响，不补造规律。

时间或分组数据先明确可用信息边界。用于选特征、调参或模型选择的探索限于训练/开发范围；最终测试信息不能反过来影响选择。原始质量盘点与用于决策的统计探索区分记录。

## 处理选择

先判断异常的语义，再考虑技术手段。极值可能来自不同地类、季次或个体规模；异常检测仅产生核查候选。比较原值、源表、同类记录和业务规则，证据不足时保留并做影响分析，不能按固定比例删点。

缺少单元格、结构性不适用、未观测变量、真实零分别处理。对未提供的需求或未来价格，属于假设/情景，不应包装成“缺失值已修复”。若采用代理量，明确其含义、依据和敏感性需求；不能把用户同意代理等同于原题被严格满足。

为语义处理和机械处理提出明确批次：原位置、发现、备选（包括不改）、推荐依据、可逆性、预期影响。获批后保存候选副本、原值、实际变换、修改数量及前后检查。数据关联检查匹配率、未匹配项、一对多展开及总量；不能因为行数增加就认定有重复错误。

自拟结构示例：源表一行“作物甲适用于地类甲/乙”展开成两个适用键时，记录同一个源行指向两个目标键；这不是新增两次观测。是否可以展开取决于表意，不能猜。报告应让读者理解行数变化，而不是仅展示处理前后数字。

## 图表与解释

| 要表达的信息 | 可考虑的图/表 | 检查重点 |
|---|---|---|
| 类别规模或两类规模口径 | 排序条形图、小多图、紧凑汇总表 | 数量与面积等不同口径分开，标单位，避免误导性双轴 |
| 分布、偏态与极值 | 直方图/经验分布/箱线图，按语义分组 | 样本量、小样本局限、极值不直接判错；不机械全套作图 |
| 变量关系 | 散点图、分组趋势或相关图 | 第三变量、时间依赖、样本条件及关联边界 |
| 时间变化 | 折线、分段趋势、必要的不确定性区间 | 缺测与真实零、时间间隔、预测与观测区分 |
| 适配、关联或处理结构 | 对应矩阵、流程示意、少量前后样例 | 解释表之间怎样对应，不把审批流程画成数据机制 |
| 结果或方案差异 | 差值图、结构占比、小多图、带单位比较表 | 同条件对比，比例的分母、总量与结构变化一起解释 |

每张关键图留下目的、口径、来源/生成位置、轴与单位、真实发现、解释、边界、建议图注与正文位置。保存可修改素材与清晰输出，图中文字最终缩放后可读。图可以只帮助认识数据，不要虚构“因此显著改善模型”。

### 自拟正反段落示例

反例：“完成了数据预处理，绘制相关热力图，发现存在明显差异，数据可用于建模。”

问题：没有说明改了什么、图回答什么、差异来自哪里或为何可用；“可用于建模”没有依据。

正例模板：“为了解不同资源类别的容量分布，我们分别比较【真实类别】的数量与【容量指标】。图【编号】显示，【来自实际统计的差异，附单位/口径】。这说明按对象数量分配资源可能忽略其容量差别，后续需要以【真实容量变量】表达限制。该图仅描述当前样本，不说明类别差异的因果来源。”

为什么较好：分析目的、真实结果、解释及边界连在一起。只有实际模型采用该约束时才能保留对应句子；若只是帮助认识结构，就说明这一用途。方括号均待真实材料替换，不能复制成结果。

另一种处理段落：“核对【字段/表】后发现【实际问题】。我们比较【备选方法】后，依据【源表或业务证据】采用【实际获批动作】；本次影响【真实数量与统计口径】，处理后通过【实际检查】。对于【未解决项】，保留【假设/待核验】并限制相关结论。”无问题时改写为检查覆盖和未修改理由，不为了套段落制造清洗。

## G2 交付与验收

交付写入既有报告和 [记录模板](../../../../workflow/templates/records.md)，不增加逐图独立报告。数据章需要真实来源结构、审计结果、实际处理与理由、EDA 发现、图表解释、模型作用或认识价值、边界和待补材料。

验收时问：读者是否理解数据对象和关联？能否区分数据事实与代理假设？能否找到改动及保留理由？重要发现是否有统计/图表支持？图注和正文是否足以避免误读？后续模型的重要条件是否有来源？没有新增发现时是否如实说明，而非虚构规律？

资料齐但解释不足时补写；需要新增统计先检查是否仍在批准范围；涉及新语义处理回原关口。数据可靠性未过不能靠优美叙述掩盖，尚未写出排版后的数据章也不自动否定已完成的数据核验。

## 参照来源和使用边界

本指南为团队操作标准与自拟示范。用户指定 C063、C094、C234 为参考论文；若要引用其具体数据分析、图表或页码，须先读取原 PDF，记录文件版本、实际 PDF 页码和所学组织方式。本轮未重新核验这些原页，不把旧聊天转述写成原文引用或已证获奖标准。借鉴分析和论证组织，不照搬参数、图数、结论或篇幅。

图的源码与图文接口统一遵循 [代码生图与图登记](../../../../workflow/rules/evidence.md#代码生图与图登记)。G0 后先判断框架/小问关系图，G2 后把实际数据图分正文、附录/支撑和内部检查；使用同一 figure_registry 引用研究主张，逐图记录 Why/What/So What/Then What，不重复维护另一套图卡。需要绘图时调用 [figure-support](../../cumcm-figure-support/SKILL.md)；它只表达已有证据，不负责研究发现。
