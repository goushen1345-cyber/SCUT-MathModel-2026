# 论文组织、论证与交付高手指南

按任务读对应章节；局部起草不要求全文已完成。摘要细节在 [摘要指南](expert-abstract.md)，数据方法在 [数据指南](../../cumcm-problem-data/references/expert-problem-data.md)，模型搜索与验证在 [建模指南](../../../../workflow/rules/modeling.md)。本文件定义写作方法和交付标准，权限遵循共享规则。

## 好论文要让读者跟得上判断

一个重要论证单元让读者理解：遇到什么困难、为什么采用这个方法、数学如何表达现实、怎样求解或验证、结果意味着什么、结论在哪些条件下成立。读者应能不认识内部阶段号也读懂全文。

“研究完成证明”常按运行顺序列模型名、指标和冻结信息；论文则围绕问题及证据组织。可以压缩重复过程，但不能删去改变判断的反证和局限；不能编造“我们手工推导/多次失败后发现”等并未发生的过程。写出可审查的理由，不索取或披露隐藏思维链。

## 章节职责与篇幅预算

以下是针对本团队复杂 C 题训练的可调整起点，正文目标合计约 22–28 页（视小问与 CORE 深度），保留机动。不是官方最低页数或获奖门槛。题型、小问数量和 CORE 深度改变时重新分配；最终以核实的当届页数口径和上限为准。不得另把背景/符号等“前四页”排除出正文凑页数。

**偏短必自检**：编译后正文明显短于规划区间时，必须核对是否缺少真实数据说明、关键约束、对照比较、验证/风险、公式推导或结果解释；缺则补研究材料或写作，禁止用空白页、重复摘要或空话灌水。已论证完整则可以短，并在内部交接注明“偏短但已自检无缺项”。

| 部分 | 应解决的阅读问题 | 训练预算示例 |
|---|---|---|
| 摘要与关键词 | 什么问题、各问方法和关键结果、贡献与条件 | 按当届摘要专页要求；不计入本表正文页数分配 |
| 背景、重述、问题分析 | 现实矛盾是什么、各问怎样递进、为什么难 | 3 页 |
| 假设与符号 | 条件为什么合理、符号/下标/单位/定义域是什么 | 2 页 |
| 数据处理与 EDA | 输入是否可靠、怎样关联、实际改了什么、发现何种结构 | 4 页 |
| 各问建模及结果 | 动机、数学模型、比较、深化、求解、结果和现实解释 | 合计 14 页，优先分给 CORE |
| 验证、风险、评价和结论 | 何证可信、何时失效、研究回答了什么 | 合计 4 页，其中各问验证/风险须分配到对应小问；全文末只留综合总结 |
| 声明/参考等正文内项目 | 真实引用、适用声明及可追溯性 | 1 页，依实际规则调整 |
| 附录与支撑材料 | 代码、详细表、复现与使用说明 | 按当届规范安排，不把核心证明全部藏入附录 |

规划时明确各章责任、所依据材料、关键图和暂缺内容。若篇幅明显少于预算，检查是否漏了真实数据说明、关键约束、比较、风险或解释；若已完整则可以短。超预算先合并重复、压缩冗余表格，不删掉影响可行性或结论的数学条件。

## 各部分怎样写

前置章节按下方“前置章节的论文转换”分工。总体框架默认模型结构图，随成熟度表达模型要素、真实共享骨架与各问增量；成熟度不足不虚构模型，也不改用流程填空。明确请求流程图时按其阅读目的另作表达，细则统一在 Figure 指南。

假设逐条说明依据、简化了什么、可能影响及验证安排，事实不改写成假设，未知量不说成观测值。符号表区分索引集合、参数、决策变量与派生量，提供单位、定义域和下标含义；首次使用仍给必要解释，避免靠读者翻表理解所有公式。

数据章写真实检查和处理，不只说“完成清洗”。让读者看懂源表到模型输入的关联/展开，分清缺值和未观测信息，再用任务相关 EDA 建立认识。图表分析方法和带注释范例见数据指南，不在此重建一套清洗要求。

每问先写建模分析段，再引入数学结构。核心目标、约束、分布或估计式应能被核对，变量、范围和必要推导明确。不能用“其余条件均线性表示”省略决定可行性的规则。算法说明解释输入输出、主要步骤、停止条件及实际求解状态，不把“调用某库”当数学方法。

候选比较围绕选择问题：相同数据、约束、信息与预算下，比了什么，差异多大，收益和代价是什么，为何保留某方案。解释实际方案结构变化，而非只有总指标；未试跑的候选只能写适配/成本判断，运行失败不能写成方法必然较差。

深化按照真实演化组织：初始不足的证据、改动动机、数学或求解变化、同条件对照、验证结论和回退。无可靠提升时，解释为什么保留简单方案；解释工具增强理解本身不证明性能提高。

风险分析说明不确定性来源、怎样进入模型或评价、影响多大、何种条件会改变选择。局限写清对结论的影响和可行补救，不用“数据有限，尚待改进”一笔带过；题意硬约束不满足不能仅当局限掩盖。结论回答原题，不引入正文没有的新实验。

## 前置章节的论文转换

本节是聊天/研究材料转成论文的方法参照；三种表达层与完整内部记录的职责见 [证据规则](../../../../workflow/rules/evidence.md#三种表达层)。修改的是论文组织，不是缩减研究发现、待核证据和风险。第一阶段只使用本次确认的题面、附件及理解材料；旧项目已有后续模型或结果，不因此成为本轮前置稿的依据。

### 章节各回答一个问题

| 章节 | 读者需要的新增信息 | 通常怎样组织与归位 |
|---|---|---|
| 背景 | 现实矛盾是什么，为什么值得解决 | 从生产、资源、市场等题目确有的冲突切入；通常 1～2 个自然段，不为充实背景扩写宏观套话 |
| 问题重述 | 题目要求做什么 | 研究对象、已知条件、主要约束、逐问任务和输出；保留影响任务含义的条件，数据充分性、推断边界和处理难点主要移入分析 |
| 问题分析 | 为什么难，这要求模型具备什么能力 | 现实/数据困难 → 简单处理为什么不够 → 建模要求；允许充分展开有信息的机制与例子，不重复翻译题面，不在这里抢先宣布未选算法 |
| 总体思路 | 整篇论文如何串起来 | 共同基础、各问分别新增什么、真实继承/比较关系、最终怎样统一解释输出；模型材料成熟时由模型框架图和 1～2 段短解释承担，明显短于逐问分析 |

重述中简短点明“题面只给出变化范围”可能是必要的已知条件；“为什么区间不足以规定联合概率、模型需表达何种依赖”放分析。按信息用途归位，不将所有带否定词的句子移走。总体思路的箭头也不自动表示把上一问最优决策固定给下一问：应依据题意区分共享数据/约束、新增因素、结果参照与真正输入依赖。

### 从内部待办推进到建模要求

以下为基于相应题意前提的自拟编辑示例，不是已完成研究或参考论文引文；实际写作先核对前提。每条内部记录及其状态仍完整保留。

| 内部研究表述/不宜原样入正文的句子 | 面向读者的转换示例 | 为什么更好、仍须保留什么 |
|---|---|---|
| 后续需要澄清连续重茬和三年豆类轮作的实现口径 | 三年豆类轮作将不同年度的种植安排联系起来，模型因此需要同时描述跨年轮作关系；具体覆盖口径须与题意核对一致。 | 从“还有工作”推进为跨年耦合要求；没有选求解算法，也没有把未确认的覆盖方式定成事实。若歧义影响当前论断，须在该处明确歧义，不能只藏进内部表 |
| 后续需要核对销售上限来源，尚未确定价格区间取值 | 销售能力影响超额产量的经济价值，模型需要区分正常销售与超额部分的计价，并明确销售上限及价格的来源口径。现有产量记录本身不等于已观测需求。 | 说明分段经济含义；销量/价格仍待核验，不得自行用产量或区间中值替代后写成已确认事实 |
| 不能把设定关系当事实，也不能据模拟认定因果，后续还需验证，结果仍取决于设定 | 共同市场因素可能使多类产品同时受影响，模型需要描述其共同变化。关系强度若来自人为设定，所得模拟结论仅适用于该设定，不能据此认定实际因果关系。 | 先讲机制与建模要求，再集中关键边界；保留“可能”“若”及设定限制，不把条件句改成已估计的关系 |

“模型需要具备……”指可由现有题意推出的表达能力，不等于已经采用、已经验证或已经批准。若现有材料连困难的含义都不能确认，明确缺口，不能靠换句式得到确定判断。内部事项只涉及工作排程而不影响读者理解时，留在交接说明；不为每条待办硬造一条论文论断。

### 信息增量与段落职责自检

形成重述、分析、总体思路后，逐个重要段落用一句话说明“本段核心任务”和“比前文新增什么”。这是编辑自检，不在论文逐段插入检查标签，也不新建独立报告。发现问题就在现有交接区记原位置、动作、目的地和保留边界：

- 同一概率缺失在重述、分析各解释一次：重述留下输入条件，合并解释到分析；必要时短回指。
- 模拟/因果边界连续出现：保留最有解释力的机制例子，把同义提醒合到最贴近相应主张处；独立可读或关键主张仍保留必要限定。
- 段首谈风险，段内又切换销售规则、两问继承和求解安排：以风险为中心重排；销售条件归对应条件说明，两问连接归总体思路。分段按实际任务，不要求各问同样段数。
- 总体思路只是再次讲每问为什么难：移除与分析重复的展开，只留下跨问关系与统一输出；必要的完整分析留在原章，不为压缩丢掉解释。

推荐顺序是主要判断 → 原因/机制/必要依据 → 建模含义及必要边界；不机械要求三句话。只有题面复述或“后续仍需研究”而没有推进时，补足困难与所需能力的联系；只有边界却看不清主要判断时，先调整中心和顺序。

### 边界的位置与密度

同一限制原则上在最合适处完整解释一次，后文简短回指。词频和“不能、尚未、仍须、后续需要、应说明、应界定、应有一致定义”的连续出现只是定位线索，不能成为禁词表、自动删句标准或通过门槛。审查分别看哪些限定不可少，哪些工作说明可移到正文外，哪些重复可以删并。

**论文正文不是检查表**：分析段以“困难→反例→判断”推进；每段末尾至多保留一句必要边界。连续“应……应……应……”或把内部待核清单直接贴进正文，属于过度防御式写作。能确定的写成判断；不能确定的一句标明未知及影响，细节留在内部交接。聊天教学口吻与论文口吻分开：前者可反复提醒，后者带读者想问题。

改变表达位置和密度不改变事实强度：未验证口径不写成已确认，模拟不写成观测，相关不写成因果；真实局限、负面结果和会改变结论的反证不得删除。若段落、图注或摘要须独立理解，或条件直接决定该主张成立，必要限定留在当地；远处的一次说明不能替代它。

**称谓**：正文与图注统一用“问题1/2/3”或“小问1/2/3”；避免同一章混用 Q1 与“问题1”（内部报告除外）。G0 总体图保持草图成熟度，框密度以约 10–20 秒能抓住共享骨架与各问增量为验收，不为早熟细节挤满画面。

### 条件表、总体图与符号接口

地类 × 季次 × 作物等多维长列表，先判断是否用条件表、关系矩阵、时间格图或代码结构图更容易核对。题意事实保留来源和例外，未知/不适用/禁止分清；不能把空白自动画成“可种”。图表承载细项，正文解释最重要的建模含义，不逐格重复。结构图与代码生成细则见 [Figure 指南](../../cumcm-figure-support/references/code-figure-guide.md#前置条件与早期建模要素)。

总体框架默认模型结构图。调用 Figure 时一并交已确认共享骨架、各问 Model Delta、阅读目的、真实参数作用关系与边界；先查报告和现有数学依据，交接缺项由研究方补材料，模型尚未形成则明确研究缺口，写作者不从日志猜。G0 只能表达题意已支持的建模要素并标草图，未确认的变量、算法、参数和结果不能提前进入模型；明确请求研究流程才画流程。新研究逻辑回原决定，既有绘图范围内不另加审批。

模型图一般放在问题分析/总体思路附近。图前说明看图目的；自拟模板：“为说明【各问】如何共用【真实模型骨架】，以及哪些组件随问题条件改变，将整体模型结构整理如图【编号】所示。”图后用 1～2 段解释共享、增量及章节展开顺序，不重念所有节点。旁注/图注承接对应边界，不把局限画成最后一步。工具受限或用户只要文字时沿用范围并注明未渲染。图型、短框、语义和快读验收按 [模型图方法](../../cumcm-figure-support/references/code-figure-guide.md#总体模型图的结构与信息预算)，不以图已生成代替验收。

符号表前自然引入，例如“为便于后续统一描述各小问，先列出全文共用的基础符号。”第一阶段仅列已确定的公共集合、索引、时间、资源等实际符号；不为凑全变量类型预定义将来的模型变量。具体变量成熟后在对应模型章增量加入。

### 软篇幅预警与验收

背景通常 1～2 段；重述以任务和条件为主；分析允许充分解释；总体思路应明显短于分析且增加跨问认识。长短先对照章节职责、信息密度和读者负担，不按字数自动判好坏。2024-C（农业种植优化）当前草稿 Reviewer 给出的重述约 900～1000、总体思路约 200～250 **非空白字符**（含标点、数字，不含标题/表格），仅是针对该稿重复的编辑参考；**示例非默认题型**，不是所有 C 题标准、优秀论文统计或硬性限额。换题须先重做结构映射，不得照搬农例段落骨架。

验收看实际修订：读者是否能分别说清任务、困难、模型要求和全篇关系？重复内容是否有明确归位？段落能否概括一个中心？真实条件、反证与内部待核项是否仍完整？图表和文字是否互补？符号是否只到当前成熟度？修正不得触发新增研究、删减内部证据或提前宣布模型。未通过时给具体移动、删并或重写动作，不能只说“更简洁”。

## 段落级写法与样章校准

重要论证单元首句概括目的或发现，再展开依据、解释与边界。可以对真正的引导句适度加粗，不要求每段加粗或满页强调。用自然、准确的主语和动作说明团队实际作出的比较和选择；“我们”不是消除空洞语言的技巧，也不能冒充人工完成 AI 工作。

### 人话书面语（防“方法论说明书腔”）

国赛读者是评委与同学，不是流程引擎。问题分析与建模动机段应像认真读题的本科队伍在讲道理，而不是顾问报告或检查清单。

| 宜 | 忌 |
|---|---|
| 困难→具体反例→判断；偶发“否则会……”“更稳妥的是……” | 段段以“因此，模型需要……”收束，整章同质 |
| 每段至多一个“模型需要/本文需要……”句式 | 抽象名词堆叠而无画面（“决策处境”“配置价值”“适配关系”连用且无例子） |
| 克制使用“本文/我们”表达判断与取舍 | 通篇主语只有“模型”，读成机构说明书 |
| 每问分析给一个落地小例子（一种地、一种作物、一种涨跌） | 把聊天教学口吻、内部待办原样写入正文 |
| 能确定的直接写判断；未知一句收束 | “应说明/应界定/应有一致定义”检查表式连排 |

自检：出声通读一节，若连续三段都能用“因此模型需要……”替换末句且结构不变，则必须改写节奏与主语。润色不得删减真实边界或反证，不得提前宣布未选算法。

反例：“采用 M1 深化模型，性能显著提升，见表 5，最终冻结 M1。”

问题：读者不知道 M1 的含义、为何改、比较条件和统计依据；冻结只表示管理状态；“显著”可能无检验支持。

自拟正例模板：“为减少【实际初始方案的问题】，我们在【有含义的原模型名称】中加入【实际改动】。在保持【真实比较条件】一致时，改进方案的【指标】由【真实值及单位】变为【真实值及单位】，同时【代价/风险】发生【实际变化】。因此，在【适用条件】下选择【最终方案的含义】；这一结果尚不能说明【证据不支持的外推】。”

优点是动机、改动、对照、选择和限制相连。没有改善就改写为未发现可靠收益与回退依据，不填入虚构数字。完整模型还需展示相应数学式，模板不能代替模型。

公式解释的自拟示例：若 x_ij 表示地块 i 上作物 j 的面积、A_i 表示可用面积，则约束应在 LaTeX 中写成 `\sum_{j\in J_i} x_{ij}\leq A_i,\ \forall i\in I`，同时定义适种集合 J_i 和面积单位。正文解释“同一地块上的种植面积之和不能超过其可用面积”；如果题目含多季/多年，须补正确索引，不能照抄这个简化式。

图表前交代分析目的或比较口径，图后解释重要发现、实际意义与边界；不逐项复述全部表格数值。模型结构图、明确请求的研究/算法流程图、数据图和结果图职责不同，只有补充信息时才并用。

首次写作选一个已有真实证据的完整单元作样章，展示动机、公式解释、比较、结果与局限。用户已有认可样章时直接沿用；需要反馈时并入已有阶段交接，不增加每章独立审批。逐章保持同一标准，最终整合不把展开过的解释再次压缩。

## LaTeX、黑字与最终 PDF

正式论文默认 LaTeX→PDF，交付源文件、图片/参考文献等依赖与可用编译说明。先检查环境、中文字体、编译器和所需包；不能编译时报告确切缺失，不静默用 Word 替代，也不谎称渲染完成。

正文、标题、图表题注、表内文字、公式编号、参考文献、页眉页脚为黑色；表格白底黑线。图形可用少量有信息作用的颜色，图内标签清晰，黑白打印仍能借线型/标记区分。超链接可用隐藏链接样式或明确黑色配置；只查 LaTeX 设置不足以证明最终 PDF 全黑。

按适用工具技能生成 PDF 并查看实际页面。自动检查辅助定位，最终页面是版式验收对象：

| 检查对象 | 通过所需证据 |
|---|---|
| 公式 | 上下标、分式、求和范围、对齐、编号与引用显示正确，无裸露源码、缺字或被裁切 |
| 字体和颜色 | 标题/正文/题注/表/编号/页眉页脚黑色且一致，中文与数学字体可读 |
| 图表 | 缩放后标签清晰；表题与表格关系正确；跨页表有合理续接；无裁切、重叠或多余空白页 |
| 编译与交叉引用 | 无未定义引用/缺失资源；检查编译告警与实际页面，必要时重编译 |
| 结构与篇幅 | 摘要、正文、声明、参考、附录及页码满足核实的当届口径；相对训练区间偏短时须有缺项自检记录 |
| 数值与复现 | 摘要/图表/正文/CSV 或结果摘要同源同版，单位与舍入一致；引用真实；源文件和支撑材料齐全 |
| 口径陷阱 | 占比分母是否写清；未实现为硬约束的内部目标不得写成“已达到”；图题注无“图1 图1”双重编号；无内部 Figure ID 印进正式题注 |

记录所查 PDF 版本与页面范围；修改后重新渲染受影响页，整体重排时复查所有受影响页面。某一页截图不能代表全篇检查。能力不足或材料缺失如实列未验收项，不写“全部通过”。

当届格式与 AI 使用要求以 governance 的官方核查流程为准，不由旧样例覆盖。**与当年校队/赛区模板或官方规范冲突时，以当届官方为准；本文件为团队默认约定。** AI 声明和详情取自实时记录，人工核验未发生就标待核验。未经上传授权不自动提交。

## 本问验证就地解释，图文与研究同源
