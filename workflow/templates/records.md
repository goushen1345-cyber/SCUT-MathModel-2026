# 按需复制的记录格式

不要一次创建所有报告；只在真实事项发生时实例化。下面所有空项是模板，不是已完成事实或授权。

## 决策条目（decisions.md）

- ID / 时间 / 小问 / 关口 / 计划版本：
- 观察、来源位置及数据版本：
- 判断（事实/假设/推断/建议）：
- 候选及差异、推荐与理由：
- 用户真实原话及消息引用（没有则待确认）：
- 人工选择、批准范围、预算、停止条件：
- 执行结果、对应实验、前后影响与待核验问题：

## 候选与实验（report.md / experiments.md）

- 候选 ID / 类别 / 原理与小例子 / 本题映射：
- 数据需求 / 预期性能 / 解释性 / 可能贡献 / 成本 / 最大风险 / 验证：
- 试跑授权 ID / 数据与协议版本 / 可用信息 / 预算：
- run ID / 代码配置路径 / 环境 / 种子 / 开始结束 / 终止状态：
- 指标与单位 / 可行性或不确定性 / 输出位置 / 基准比较：
- 实现失败、未试跑淘汰或证据淘汰（区分）：
- M0不足证据 → 改动假设 → M1 → 实验 → 保留或回退：

## 论文证据（paper_evidence/<范围>.md）

- 主张 ID / 状态（待验证、支持、不支持、失效）：
- 数据、模型、协议、实验、图表及版本：
- 证据说明与反证 / 适用边界：
- 可写入论文的准确表述 / 禁止夸大成什么：

## AI 使用（ai_usage_log.md）

- 阶段、日期、工具名称、版本/型号（无法取得则如实注明）：
- 具体用途、主要提示方式与使用过程、典型交互引用：
- 生成文件、采用内容及人工修改：
- AI 检查与实际人工核验分别记录；核验者、方法、结果或待核验：
- 人类关键决定及 decisions 引用：

## review_package.md

- 审查 ID、范围、目标问题、当前状态：
- 原题要求、数据口径及版本、关键假设：
- 文件清单（相对路径、用途、SHA256）；外部审查需上传的实际文件：
- 模型/代码/配置/实验/图表，失败路线与已知局限：
- 复核命令与预期检查内容（不是预设应通过的答案）：
- 要求 Reviewer 返回：问题ID、证据位置、严重性、影响、复现/验证步骤、建议、不确定性；不批准、不改正式文件：
- Worker 回应：接受并修正 / 有证据反驳 / 待检验；涉及越范围时申请人工确认：

## 研究报告交接区（嵌入现有 report.md）

共用字段：本阶段问题/现实矛盾；关键发现及证据；方法理由与备选；必要数学表达；真实比较/验证；结论、反证与边界；可写内容、待补项和对应主张。字段只填当前阶段实际可得材料。

数据摘要表：对象/源位置｜检查发现及类型｜处理候选｜实际动作或保留｜理由与批准引用｜修改数量/统计口径｜前后数量和分布影响｜数据版本｜核验与局限。无修改写清检查结果，不制造处理数量。EDA 另写“分析问题—图表/统计依据—真实发现—解释—模型作用或认识价值—推断边界”，不把审计表当 EDA。

单问模型交接：任务/输出；建模动机；假设及适用条件；索引、符号、单位与定义域；目标/约束或统计表达及现实含义；关键推导；求解与终止状态；候选实质区别和公平比较；不足证据、实际改动、对照、回退；结果与方案结构；独立验证、风险及局限。B 后填已完成部分，D 后增量更新，不要求 B 前就有最终结果。

## Model Delta（嵌入现有小问 report.md）

使用时机与维护方式见 [建模指南](../rules/modeling.md#model-delta-交接)。共享骨架复用研究方现有 report.md 的说明；本节只记录本问增量，不复制一套模型报告或运行日志。

- 共享基础模型：来源路径/章节、真实版本及适用范围；本问模型版本/状态和替代或回退的旧版本引用：
- 共享骨架引用：已确认的决策变量、目标、主要约束、计算关系与输出；参数 → 实际作用组件及关系语义的来源位置；未定/缺失材料：
- 同版本数学说明/实现/结果核对；计划与实际差异、真实确认范围及待核冲突（代码已运行不代表已获批准）：

| 比较项 | 共享基线 → 本问（新增/修改/不变/未定） | 来源位置、对应主张与适用版本；必要边界 |
|---|---|---|
| 参数输入增改 | | |
| 目标 | | |
| 约束 | | |
| 关系机制/中间计算（含实际销售规则等题目特有机制） | | |
| 新增或改变的评价方式 | | |
| 输出变化 | | |
| 保持不变的共享部分 | | |

只填写已存在材料；计划、已实现和未定状态明确区分。各项可引用同一来源，不重复抄录；未共享或不适用说明实际原因。Figure 优先读取共享骨架和此表，不从日志推测各问增量。

## 图表交接（引用单一 registry）

报告和论文证据只引用 Figure ID 及相应主张，不重复维护图卡。候选图完整字段放在项目 paper_evidence/figure_registry.md，见本文件下方模板；已存在的旧图卡合并时保留来源并改成引用。精确数值表仍使用其真实数据/口径和论文证据映射，不为套 registry 强制改图。

## 章节写作范围（嵌入 paper_evidence 的交接区）

- 触发点、用户请求或既有写作计划引用、来源证据版本：
- 可写章节和准确结论；禁止写成事实的预期；尚缺材料及原因：
- 稿件路径、负责人、版本、状态（草稿/待复核/已审）：
- 审阅者/方式/依据/范围/日期；AI 自检与人工确认分开：
- 上游变更影响的主张、图表、章节位置和复核结果：
- B 第一轮与 D 第二轮实际增量；全文整合保留/调整的关键论证：

这些字段描述文稿，不代表研究推进或冻结。阶段触发与权限见 [证据规则](../rules/evidence.md#阶段交接与写作)；不把示例字段填为虚构事实。

## 前置章节转换（沿用上述交接区）

仅当前置稿实际起草/修订时填写，方法统一见 [论文指南](../../.agents/skills/cumcm-paper-builder/references/expert-paper-writing.md#前置章节的论文转换)。这是内部编辑记录，不作为论文新章节，不另建报告。

- 本轮确认的来源范围及证据版本；不适用的旧下游成果：
- 正文章节分工：背景的现实矛盾；重述的对象/条件/约束/逐问任务/输出；分析的困难—简单处理不足—建模要求；总体思路的共享基础/新增因素/真实衔接/统一输出：
- 内部未知/待办/歧义/风险/待核证据的原位置（完整保留）；对应正文必须保留的边界及位置：
- 需要编辑的重要段落：原位置与核心任务｜相对前文的新增信息｜保留/移动/合并/删除重复/重写｜目的地与理由｜不可丢失的条件/证据｜修后核对结果：
- 条件长列的表达选择及理由：短文字/条件表/矩阵/时间格图/代码结构图；细目与正文分别承担什么：
- 总体思路：拟引用的 Figure ID 或文字结构；按 [图登记规则](../rules/evidence.md#代码生图与图登记) 区分请求图型与当前材料成熟度，不能用阶段研究流程代替默认模型框架；共享骨架与 Model Delta 的来源、边语义、每问新增或待补；图前目的和图后关键关系；实际渲染状态及已有范围限制：
- 软篇幅检查：哪些段落职责重叠，采取何种具体删并/移动；不设统一字数阈值：

可采用的正文骨架（按题目调整，不复制占位为事实）：背景讲现实矛盾；重述交代任务与条件；逐问分析说明困难及所需模型能力；总体图/短文串起各问。符号说明前自然引入“为便于后续统一描述各小问，先列出全文共用的基础符号。”随后只列当前已确认的公共符号，未来变量留待模型形成后定义。

交付时复核内部事项及其状态未因删并正文而丢失、未确认口径未变成事实、必要边界仍能约束对应主张。正文外可集中说明稿件成熟度与待补项，不能用远处说明代替关键论断当地的条件。

## 审查包补充（沿用 review_package.md）

- 本轮变化、上轮问题 ID/状态、拟作决定和当前应验收阶段：
- 对应专业指南/团队交付约定；实际报告、原始依据、公式、稿件和图表版本：
- 直接/间接受影响主张与章节；已读/缺失材料：
- 问题类型（科学正确/证据/研究交接/语言/约定版式/一般建议）：
- 表达问题补充：章节职责/信息增量/段落中心/过度防御；必须保留的真实边界｜可移动或删并的重复｜具体处理及目的地；词频只作线索：
- 关闭证据：独立复算/原始依据，或修订段落及边界保留核对，或最终 PDF 渲染页；不能只填“已改”：

## Validation Plan（嵌入 questions/Qk/report.md）

在 C 确认前形成；说明本问最重要的不确定性和最终主张，参照 [适用矩阵](../rules/modeling.md#每问可信度验证矩阵)。各类适用性简短列明；实际实验可覆盖多个类别，共用证据不重复实施。

| 验证 ID/类别 | 待验证主张/来源版本 | 采用或不适用及理由 | 对象/参数/情景范围与依据 | 对照/控制条件 | 指标、判断标准及依据 | 输入输出、预算/停止条件 | C 计划版本/授权引用 |
|---|---|---|---|---|---|---|---|

正确性与现实解释不得用空白或笼统“不适用”略过。缺批准记待确认；缺实验记研究未做，不能用不适用替代。无需新增 validation.md 独立报告。

## Validation Results（同一小问 report.md）

| 验证 ID/计划引用 | 实际执行状态、版本与条件偏差 | 代码/run/原始输出 | 结果及单位/不确定性 | 支持、部分支持、不支持或待验证 | 失败/敏感点/风险 | 假设依赖与失效边界 | 可写表述/禁止夸大 | 图表候选 ID |
|---|---|---|---|---|---|---|---|---|

随后写 D 可信度总结：已验证什么和结果；稳定与敏感结论；最大风险；什么时候失效；哪些依赖人为假设；没有证明什么；本问论文应呈现的验证；继续深化/收缩主张的价值和成本；尚待用户作的决定。未执行或失败如实保留，表中有字不等于验收通过。

## figure_registry.md（项目 paper_evidence 内唯一图索引）

图 ID 在研究和稿件之间稳定，论文最终编号另行映射。首次有实际候选才建立，不预填一套“已完成”图。

- Figure ID / 图名 / 类型（总体模型结构、用户明确请求的研究流程、算法流程、数据/结果等）及请求依据 / 关联小问与验证或主张 ID：
- 目的与取舍：为何用图；若表更适合则记录改用表/不画的理由：
- 数据或逻辑来源：路径、版本/哈希、真实研究证据或结构核对依据：
- 模型结构图补充：共享骨架/各问 Model Delta 的来源与版本；模型组件、参数作用位置及关键边 → 对应来源/主张；只引用必要映射，不复制研究日志：
- What：对象、单位、轴/节点含义、样本/情景、分组及比较口径：
- 生成源码/结构定义、代码版本/哈希、环境/字体、完整复现命令：
- 输出文件及版本/哈希（保留向量/清晰预览等实际生成格式）：
- 建议章节、正式图号映射、正文/附录或支撑/内部类别：
- Why：图前引导；So What：图后主要发现；Then What：对认识或后续判断的实际作用：
- 图注、结论边界、不得声称的内容、正文位置：
- 当前状态：候选/待来源或逻辑/待生成/待视觉验收/可入稿/待重生成或复核/不采用：
- 源码复现结果、逻辑核对依据、视觉验收者/版本/页面范围分别记录；不是人工检查则不能写人工已核验：
- 总体模型图语义简化核对：原表达/来源 → 图中短语；代理、范围、条件和关系含义是否保留；结果或待修项：
- 总体模型图 10～20 秒速读检查：实际渲染文件/版本、图或嵌入页尺寸与查看缩放；核验者及方式（AI 自检/独立 AI 检查/实际人工，人工未做如实记未做）；按 [模型图指南](../../.agents/skills/cumcm-figure-support/references/code-figure-guide.md#总体模型图的结构与信息预算) 记录模型骨架及各问增量的识别结果、实际计时或未计时、结论/待修项；不能以生成完成替代通过：

状态是图形元数据，不改变研究 state。缺源码、输入、有效来源或实际视觉检查的图不能标可入正式稿；Figure 可交回条目供主执行者合并，不与其争写 registry。
