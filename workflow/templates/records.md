# 按需复制的记录格式

不要一次创建所有报告；只在真实事项发生时实例化。下面所有空项是模板，不是已完成事实或授权。

## 决策条目（decisions.md）

- ID / 时间 / 小问 / 关口 / 计划版本：
- 观察、来源位置及数据版本：
- 判断（事实/假设/推断/建议）：
- 候选及差异、推荐与理由：
- 用户真实原话及消息引用（没有则待确认）：
- 人工选择、批准范围、预算、停止条件：
- 执行结果、对应实验、前后影响与待核验问题：

## 候选与实验（report.md / experiments.md）

- 候选 ID / 类别 / 原理与小例子 / 本题映射：
- 数据需求 / 预期性能 / 解释性 / 可能贡献 / 成本 / 最大风险 / 验证：
- 试跑授权 ID / 数据与协议版本 / 可用信息 / 预算：
- run ID / 代码配置路径 / 环境 / 种子 / 开始结束 / 终止状态：
- 指标与单位 / 可行性或不确定性 / 输出位置 / 基准比较：
- 实现失败、未试跑淘汰或证据淘汰（区分）：
- M0不足证据 → 改动假设 → M1 → 实验 → 保留或回退：

## 论文证据（paper_evidence/<范围>.md）

- 主张 ID / 状态（待验证、支持、不支持、失效）：
- 数据、模型、协议、实验、图表及版本：
- 证据说明与反证 / 适用边界：
- 可写入论文的准确表述 / 禁止夸大成什么：

## AI 使用（ai_usage_log.md）

- 阶段、日期、工具名称、版本/型号（无法取得则如实注明）：
- 具体用途、主要提示方式与使用过程、典型交互引用：
- 生成文件、采用内容及人工修改：
- AI 检查与实际人工核验分别记录；核验者、方法、结果或待核验：
- 人类关键决定及 decisions 引用：

## review_package.md

- 审查 ID、范围、目标问题、当前状态：
- 原题要求、数据口径及版本、关键假设：
- 文件清单（相对路径、用途、SHA256）；外部审查需上传的实际文件：
- 模型/代码/配置/实验/图表，失败路线与已知局限：
- 复核命令与预期检查内容（不是预设应通过的答案）：
- 要求 Reviewer 返回：问题ID、证据位置、严重性、影响、复现/验证步骤、建议、不确定性；不批准、不改正式文件：
- Worker 回应：接受并修正 / 有证据反驳 / 待检验；涉及越范围时申请人工确认：
