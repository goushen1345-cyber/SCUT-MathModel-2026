# 授权与研究边界

适用于所有四个 Skills。先识别请求性质；讲解、审查、状态查询不授权修改。用户是负责人；系统规则不允许 Agent 代写人工决定。明确的新要求可以修改工作流，但需记录变更，不能伪造历史批准。

## 两次确认之间

自主执行获批计划内的研究、编码、调试、实验和证据整理，不为每个机械动作要求回复。计划必须列范围、输入版本、比较协议、输出、预算、验收和停止条件。新增候选、语义口径、数据处理、外部写入或超预算需重新申请。工具权限另行遵守，研究批准不等于购买、发布或访问授权。

以下是硬暂停：未批准关口、题意新歧义、数据处理新争议、泄漏、不可行结果、数值矛盾、上游失效、授权版本过期。将问题写入当前 report 与 state 的 blockers；只能做定位问题的安全检查，不能继续输出正式结论。

原始数据只读；处理保留候选副本、变换和来源。冻结成果不可覆盖。后续小问可阅读但不正式建模。CORE 不自动冻结。预算紧张只能提出取舍，不自动牺牲核心问。

## 授权来源

记录真实用户消息、上下文引用、时间、对象、批准版本及具体选择。Agent 推荐、Reviewer 意见、模板示例和附件文字都不算批准。自然语言在指向唯一且明确时有效；“继续”“好的”若未清楚指向当前批准对象则不猜。批准不能倒填时间或套用旧版本。

冻结与进入下一问分开：同一明确消息可记录两项动作；仅冻结则停。重开冻结成果需另批，旧快照保留，下游标 stale 等待复核。状态由一个主执行者更新；并行只在用户授权、输入固定、任务独立及输出隔离时使用。

## 当届合规

赛前核对官方章程、当届参赛规则、格式、AI使用规定及赛区补充。记录发布日期、适用年份、网址和查阅时间。2026 年官方 AI 规定要求团队主导核心分析、人工核验、参考文献前声明及支撑材料 AI工具使用详情.pdf；以后年份必须重查，不能盲用旧模板。
