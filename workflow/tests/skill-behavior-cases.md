# Skills 行为回归场景

本文件保存代码生图、每问可信度、前置论文转换与总体模型图的行为场景及可重复测试输入，历史场景继续保留；不取代现有 statectl 程序测试，也不要求新建测试赛题项目。所有数字与案例均为合成测试材料，不是比赛研究成果。

## 怎样运行

给独立执行者相应 Skill、其可访问依赖和下方“输入”，让其输出当前阶段下一条聊天答复及相应报告片段。用于生成答复的执行者不读取本文件的“验收”栏或其他执行者结果；评估者随后对照观察结果。模拟阶段不初始化真实项目、不伪造批准、不运行新实验。已给状态是场景前提，结论只能基于给定材料。

记录读取文件、完整答复、哪些动作实际发生、评估理由和限制；不能仅匹配“灵敏度”等关键词判通过。状态的实际执行/恢复另用独立完整任务检查，不能由答复模拟证明。
