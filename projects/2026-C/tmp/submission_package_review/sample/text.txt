基于几何建模与智能算法的烟幕干扰弹投放策略优化
摘要
在精确制导武器广泛应用的背景下，利用无人机投放烟幕干扰以遮蔽来袭导弹对地
面目标的视线，已成为近距离防护的重要手段。如何在平台性能与时序约束下定量评估
并优化烟幕的遮蔽效果，是决定防护效能与投放策略优劣的关键科学问题。本文针对该
问题开展建模与优化研究。
针对问题一，在导弹直线等速、无人机等高直线巡航、烟幕起爆后形成半径恒定且
竖直匀速下沉的球云、目标以圆柱体并据凸体几何确定可见性的前提下，建立三维对抗
几何模型，通过可见表面采样、向量化计算与自适应时间扫描确定完全遮蔽时刻。结果
显示，在 FY1–M1–单弹场景下，完全遮蔽时长为 1.391638 s，遮蔽区间为 [8.056448
s, 9.448087 s]。
针对问题二，在统一运动学框架下，将真实目标近似为几何中心点，以起爆有效窗
内的遮蔽时长为目标，构建联合优化无人机航向、速度、投放时刻与引信延时的模型，
并采用自适应粒子群优化算法搜索最优解。结果表明，在 FY1–M1–单弹场景下，最优
策略为航向角 0.1245 rad、速度 79.000 m/s、投放时刻 0.175 s、引信延时 0.920 s，
对应的完全遮蔽时长为 4.810 s，主遮蔽区间为 [1.106 s, 5.909 s]，起爆时刻为 1.095
s。
针对问题三，研究单机三弹协同投放，以三枚烟幕弹形成的遮蔽区间并集时长为目
标，采用实数编码遗传算法优化投放时刻与引信延时。相较于问题二的单弹情形，本问
在同一平台下引入多弹协同，进一步提升了模型维度和搜索复杂度。结果显示，在 FY1–
M1–三弹场景下，总遮蔽时长为 6.750 s，三枚干扰弹的有效遮蔽时长分别为 4.150s,
2.580s 和 0.000s，投放策略结果见 result1.xlsx。
针对问题四，研究三机协同单弹投放，以各无人机投放烟幕形成的遮蔽时长并集为
目标，在几何先验裁剪可行域后，采用实数编码遗传算法进行优化。该问题将协同拓展
到多平台，强调不同飞行器在时空上的配合。结果显示，在三机协同场景下，总遮蔽时
长为 13.980000 s，投放策略结果见 result2.xlsx。
针对问题五，研究五机协同对抗三导弹的场景，建立联合优化无人机航向、速度与
投放时序的高维模型。为缓解维度灾难，提出外层航向–速度网格搜索与内层贪心合并
的联合框架，并结合遗传算法局部精修求解。相较前几问，本问规模最大、变量最多，
对算法的全局搜索与局部收敛能力均提出更高要求。结果显示，在五机三导场景下，总
遮蔽时长为 41.05s，投放策略结果见 result3.xlsx。
总体而言，本文建立了从单机单弹到多机多弹的层级化建模体系，并提出相应优化
方法，为复杂对抗条件下的无人机协同提供了计算框架与求解思路。
关键词：遮蔽判断准则；APSO 算法；GA 算法；内外联合优化；全局贪心策略

一、 问题重述
1.1 问题背景
在现代精确制导武器广泛应用的条件下，利用无人机投放烟幕干扰弹在目标前方形
成遮蔽云团，可以有效降低来袭导弹的打击精度，具有低成本与高效费比的特点。当前
技术已能够通过时间引信精确控制烟幕起爆时刻，使其在目标前方特定空域形成具有稳
定持续时间的云团屏障。然而，在实际防护过程中，无人机平台的速度与航向受限，干
扰弹的投放时机和延时设置也存在约束，如何在复杂约束下设计合理的投放策略，使得
目标在导弹来袭过程中获得尽可能长的有效遮蔽时间，是一个兼具理论价值与应用前景
的重要问题 [1]。
1.2 问题重述
本文围绕“无人机—烟幕干扰弹—导弹”对抗系统，针对不同规模与场景，提出以
下研究任务：
问题一：在给定无人机 FY1 的航向、速度与投放—起爆时序条件下，计算其单枚
烟幕弹对导弹 M1 的有效遮蔽时长。
问题二：在单机单弹情形下，联合优化 FY1 的航向角、巡航速度、投放时刻与引
信延时，确定使遮蔽时长最大的投放策略。
问题三：在单机三弹情形下，设计三枚烟幕弹的协同投放与引信延时策略，并输出
对应的结果文件。
问题四：在三机协同情形下，联合优化 FY1、FY2、FY3 的飞行参数与投放时序，
确定使导弹 M1 遮蔽时长尽可能长的策略，并输出结果文件。
问题五：在五机对抗三导弹的综合场景下，构建多机多弹协同优化模型，给出覆盖
三枚导弹的总体投放方案，并输出结果文件。
二、 问题分析
2.1 问题 1 的分析
本问要求在统一坐标与时标下，依据导弹直线飞行、无人机等高巡航、烟幕云团下
沉扩散以及目标几何简化等条件，建立可见性判定模型。其核心是通过导弹—目标视线
与球形云团的几何关系来度量遮蔽时长。
难点在于三维几何与时间演化的耦合，以及在视线与球面近切时的数值稳定性。若
阈值设定不当，容易出现误判。
总体思路是通过规范化的运动学表达与稳健的几何判据，确保遮蔽度量的可靠性。
2

2.2 问题 2 的分析
在单机单弹情形下，本问需要联合优化无人机的航向角、速度、投放时刻与引信延
时，以实现遮蔽时长最大化。
难点在于：一方面，遮蔽时长作为目标函数，来源于几何可见性判据，导致优化问
题非凸且不光滑；另一方面，平台性能约束、飞行安全要求与投放窗口限制叠加，使可
行域较小。
为此，应构建带约束的连续优化模型，通过适度简化变量范围和合理的变量归一化，
减轻搜索难度。同时结合全局启发式搜索与局部调整方法，提升最优解的可行性与稳定
性。
2.3 问题 3 的分析
单机三弹情形下，本问需设计三枚烟幕弹的投放时刻与引信延时，使得遮蔽区间的
并集尽可能长。
其难点在于三枚弹药在时序上的相互作用，以及烟幕云团在空间和时间上的重叠效
应。区间并集的计算必须避免重复计量，否则会高估遮蔽时长。同时，决策变量增加导
致搜索空间显著扩大。
为应对复杂性，可将问题分解为“单弹遮蔽区间评估—区间并集运算—约束修复”
三个步骤。通过实数编码的变量表达，并结合先验裁剪与快速合并算法，可以在保证精
度的同时控制计算规模。
2.4 问题 4 的分析
三机协同单弹情形下，需同时考虑多个无人机的航向、速度及投放—起爆时序，以
求整体遮蔽覆盖最大化。
此时的难点主要在于决策变量数量大幅增加，平台之间的协同关系复杂：既可能存
在冗余覆盖，也可能形成互补效果。加之优化模型呈现强多峰性和对称性，增加了求解
难度。
合理的建模思路是利用几何先验先行裁剪不可能的参数区域，缩小有效解域；再通
过分层优化，将几何参数与时序参数分别处理，从而提高求解的可控性。
2.5 问题 5 的分析
在五机对抗三导弹的综合场景中，需要同时规划多架无人机的飞行与投放方案，以
最大化对三枚导弹的总体遮蔽覆盖。
其难点最为突出：一是多平台、多目标、多弹药带来的高维耦合与组合爆炸；二是
不同导弹的威胁优先级和有限平台资源之间存在分配与调度冲突；三是遮蔽区间的跨导
弹叠加，使得优化目标更具复杂性。
3

为解决该类大规模问题，可采用分层化与混合式的求解思路：外层进行几何配置与
资源指派，降低问题维度；内层完成时序合成与遮蔽区间合并，保证遮蔽时长的合理性。
通过全局启发式算法与局部精修结合，并辅以主导变量网格化与贪心修复，可在一定程
度上缓解维度灾难，提升优化效率与解的质量。
三、 模型假设
为保证建模的合理性与可解性，在题目条件的基础上，本文作出如下假设：
1. 假设导弹沿固定方向做匀速直线飞行，不考虑机动规避与制导修正。
2. 假设无人机以恒定高度、固定航向角和速度直线巡航，不考虑加减速与高度机动。
3. 假设起爆后烟幕迅速形成理想球形云团，半径恒定，并以恒定速度在竖直方向匀
速下沉，不考虑风场、湍流及非均匀扩散效应。
4. 假设不考虑风速、气象条件和地形起伏对无人机飞行及烟幕扩散的影响。
5. 假设无人机与导弹的几何尺寸对遮蔽判定影响可忽略，均视为质点处理，仅保留
其位置与速度信息。

10.2 误差分析
模型的误差来源主要分为几个部分.
在遮蔽判断条件上, 本文在问题 1,2 中使用了圆柱表面离散化搜索检验算法, 但是在
问题 3,4,5 的分析和求解中为了引入遗传算法带来的巨额计算量进行了“点遮蔽”判断
条件简化, 将真目标圆柱体近似为“中心点”，忽略了目标不同表面的几何可见性差异；
其次, 所有问题均有采用离散化网格的数值实现方法, 时间步长的选取会影响程序
对物理过程的仿真模拟, 进而给优化过程带来影响. 本文选取的步长兼顾了计算效率和
准确度, 并且根据不同的适用场景 (如多分辨率搜索) 采用不同精度的搜索方法, 误差的
影响控制在可承受范围内, 所得结果都符合直观判断的可行解.
最后, 问题 4 和问题 5 的优化过程中为了加快遗传算法的优化过程, 环节在高维优
化时带来的维度灾难影响, 我们通过参数空间缩减, 启发式初始化等策略加快了搜索过
程, 没有最优解的数学原理保证, 同样会引入计算和结果数值误差.
十一、 模型的评价与推广
11.1 模型的评价
11.1.1 模型的优点
1. 本文提出的三维几何对抗框架和遮蔽判定准则，能够精确描述无人机投放烟幕对
导弹视线的遮蔽过程，既符合题目要求，也可推广到其他类似的空间对抗问题；
2. 针对不同问题的复杂度，分别采用了自适应粒子群优化（APSO）、遗传算法（GA）、
参数空间剪切以及外—内联合优化与全局贪心算法，实现了在高维搜索空间中的
快速收敛，兼顾了全局搜索与局部精修的平衡；在保证精度的前提下，通过参数
空间缩减、多分辨率搜索、适应度惩罚等策略有效缓解了高维优化问题的维度灾
难，使整体计算流程在有限时间内完成, 并给出令人信服的投弹策略方案。
3. 通过绘制 x, y 平面图, 直观地验证了模型对关键参数扰动的响应符合直观物理规
律，数值结果具备较好的稳定性和解释性.
28

11.1.2 模型的缺点
1. 为保证建模与计算可行性，假设烟幕为半径固定、竖直下沉的理想球体，目标被
近似为中心点，未能充分考虑气流扰动、烟幕扩散及目标几何差异；
2. 启发式优化算法（如 GA、PSO）虽然能够有效给出高质量解，但无法严格保证全
局最优，部分结果可能依赖初始种群与参数设定；
3. 为了避免计算过于复杂，对部分约束（如无人机飞行动力学模型、导弹探测系统
的真实视域特性）未做深入考虑，这在实际工程中可能引入偏差。
11.2 模型的推广
1. 本文所提出的“目标可见性判定 + 遮蔽时长优化”思路，可应用于光学/雷达对
抗、无人机群协同干扰、舰船编队隐身等相关问题；
2. 多分辨率搜索、外—内联合优化、启发式与局部精修结合的求解框架，适用于其
他高维、非凸、黑箱类优化问题；
3. 在问题 5 的全局粗搜与局部精搜的框架中, 相较于精修后的总遮蔽时长 41s, 全局
粗搜时已经获得了接近 39s 的效果, 实际应用中, 为了稳定性和速度考虑, 可以提
出新的参数空间剪枝方法, 重点改进全局粗修搜索到的精确解, 使得最终决策方案
不必完全依赖长时间的黑箱优化方案. 能适应真实反导场景中的快速决策需求.

123 def missile_trajectories(m_init, t_grid, speed=MISSILE_SPEED):
124 M0 = m_init.copy()

149 def generate_candidates_for_drone(dr_idx, dr_init, v, theta_rad, t_grid, M,

150 Tn = len(t_grid)
151 dir_vec = drone_dir(theta_rad)
152 V_vec = v * dir_vec
153 t_releases = np.arange(0.0, t_grid[-1] + 1e-9, RELEASE_DT)
154
155 cands = []
156 for t_rel in t_releases:
157 P = dr_init + v * t_rel * dir_vec
158 for fuse in FUSE_SET:
159 tau = t_rel + fuse
160 if tau > t_grid[-1]: # 起爆晚于地平线
161 continue
162
163 E = explosion_point(P, V_vec, fuse) # (x_e, y_e, z_e)
164 if E[2] <= 0.0: # 起爆点不得在地面/地下
165 continue
166
167 # —— 关键：云团有效到“落地/20s到期/全局上限”的最早时刻 ——
168 t_end = min(tau + CLOUD_TAU, tau + E[2] / CLOUD_SINK_V, t_grid[-1])
169 if t_end <= tau:
170 continue
171
172 j0 = int(np.ceil(tau / DT))
173 j1 = int(np.floor(t_end / DT))
174 t_sub = t_grid[j0:j1 + 1]
175
176 C = cloud_center_at(E, tau, t_sub) # (len,3)
177 M_sub = M[:, j0:j1 + 1, :] # (M,len,3)
178 N_sub = N_hat[:, j0:j1 + 1, :] # (M,len,3)
179 Dist_sub = Dist[:, j0:j1 + 1] # (M,len)
180
181 delta = C[None, :, :] - M_sub # (M,len,3)
182 dot = np.sum(delta * N_sub, axis=2) # (M,len) —— 投影长度
183 delta2= np.sum(delta * delta, axis=2) # (M,len)
184 perp2 = delta2 - dot * dot # (M,len)
185
186 # —— 线段判定：0 <= dot <= Dist_sub （不是射线！）
187 cond = (perp2 <= (R_CLOUD ** 2) + 1e-12) & (dot >= -1e-12) & (dot
38

<= Dist_sub + 1e-12)
188
189 mask = np.zeros((M_sub.shape[0], Tn), dtype=bool)
190 mask[:, j0:j1 + 1] = cond
191
192 score = float(np.count_nonzero(mask) * DT)
193 if score <= 1e-12:
194 continue
195
196 cands.append({
197 'drone': dr_idx,
198 't_release': float(t_rel),
199 'fuse': float(fuse),
200 'tau': float(tau),
201 'P': P.copy(),
202 'V': V_vec.copy(),
203 'E': E.copy(),
204 'mask': mask,
205 'score': score,
206 })
207
208 if not cands:
209 return []
210 cands.sort(key=lambda x: x['score'], reverse=True)
211 kept = cands[:min(topk, len(cands))]
212 print(f" [Cand] 无人机#{dr_idx}: 原始{len(cands)} -> 预筛保留 {len(kept)}
(Top-{topk})")
213 return kept

216 # ===================== 3. 内层贪心选择（含重叠收益，已去掉逐步打印）
=====================
217 def greedy_select(candidates, t_grid, alpha_overlap=ALPHA_OVERLAP,
return_covered=False):
218 if not candidates:
219 return ([], 0.0, None) if return_covered else ([], 0.0)
220 M = candidates[0]['mask'].shape[0]
221 Tn = len(t_grid)
222 covered = np.zeros((M, Tn), dtype=bool)
223 chosen = []

224 per_drone_count = {}
225 per_drone_times = {}
226
227 def conflict(dr, t_rel, per_times):
228 for tr in per_times.get(dr, []):
229 if abs(tr - t_rel) < MIN_GAP_SAME_DRONE - 1e-9:
230 return True
231 return False
232
233 while True:
234 best_idx = -1
235 best_gain = 0.0
236 for idx, c in enumerate(candidates):
237 dr = c['drone']
238 if per_drone_count.get(dr, 0) >= MAX_BOMBS_PER_DRONE:
239 continue
240 if conflict(dr, c['t_release'], per_drone_times):
241 continue
242 m = c['mask']
243 new_cover = m & (~covered)
244 overlap = m & covered
245 gain = (np.count_nonzero(new_cover) + alpha_overlap *
np.count_nonzero(overlap)) * DT
246 if gain > best_gain + 1e-12:
247 best_gain = gain
248 best_idx = idx
249 if best_idx < 0 or best_gain <= 1e-12:
250 break
251 c = candidates.pop(best_idx)
252 covered |= c['mask']
253 dr = c['drone']
254 per_drone_count[dr] = per_drone_count.get(dr, 0) + 1
255 per_drone_times.setdefault(dr, []).append(c['t_release'])
256 chosen.append(c)
257
258 total_cover_time = float(np.count_nonzero(covered) * DT)
259 if return_covered:
260 return chosen, total_cover_time, covered
261 else:
262 return chosen, total_cover_time
