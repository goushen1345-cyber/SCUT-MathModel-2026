## 一、全题要解决什么

小区用电与光伏出力随时间变化，外网不同时段的购电成本不同，电池可以把电能从一个时段转移到另一个时段，但容量、充放电速度和效率都有限。需要共同决定何时买电、买多少，以及何时充放电，在保证实际负载得到满足的条件下减少购电总费用。

主要矛盾有三层：低价时多买可以减少高价购电，但要占用有限储能并承担损耗；按预测少买可能遭遇实际缺口，按预测多买又可能支付多余计划电费；新预报能帮助调整决策，但增购和减购都受结算规则影响，因此预报变新并不保证最终费用下降。

全题以**优化决策**为主，能量守恒和储能动态提供物理框架，预测与误差分析支持后续不确定条件下的决策。题面没有要求建立电网拓扑、求解电压潮流或设计线路，不因题名含“微网”就归为网络构建题。

### 核心原理及其含义

1. **能量守恒与储能状态递推。** 每个时段的供给、负载、充电和剩余去向须对应；储电量由上一时段状态累计变化而来。若充放电量定义在外部母线侧，关系可写为“S下一时段＝S当前＋充电效率×充入电量−放出电量/放电效率”。这只是解释计量位置的条件表达，效率具体口径尚未确认。
2. **功率与电量量纲一致。** 若P是10分钟区间的平均功率，则电量E=P×(1/6)小时。5000kW在10分钟内对应约833.33kWh，这是同一计量侧的功率上限换算，不是已经确定的电池内部能量变化上限。若表中为瞬时功率，还需先明确如何表示区间平均值。
3. **储能套利受损耗约束。** 例如，若充、放电效率各为90%，外部充入100kWh，最终可对外放出81kWh。只比较峰谷电价高低不足以判断套利是否划算，还要计损耗、容量占用及供电需求。这里的81kWh为解释性条件算例，不是题目已确认效率解释或实验结果。
4. **时序信息约束。** 决策依赖已获得的信息；附件中能看到未来实际值不等于当时能够知道。6:00发布的预报1小时应对应7:00，不能按1:00使用；此例说明发布时间与目标时间的映射。
5. **带非对称代价的决策。** 少买引发5倍价格应急，多买依然按计划收费，调整还有不同增减代价。应以真实结算下的总费用评价，不以单一预测误差或单一紧急费用决定优劣。

### 8.6 共享关系、CORE及下一步确认

共享基础是物理供需关系、有限储能及其跨时段状态、设备参数和统一量纲。各问的真正输入依赖是相应附件、已明确的信息/结算规则，以及同一连续运行中此前形成的储电量；Q1具体策略数值不是Q2的必需已知量。研究工程上可以复用已核查的结构与记账，但不能沿用Q1特有首尾相等或把同一费用对象重复计入。Q4-2与Q4-3分别承接Q2/Q3权限，不能仅因为都属于Q4就合并。

建议Q3作为CORE：需在不断更新的信息、有限电池和有代价的改约之间作判断，且必须评价预报价值。Q2是可信度基础：如果它偷看未来、时段错位、初态不实或能量账不守恒，Q3/Q4后面的节费比较就失去依据。该优先级是题意理解后的建议，不是官方分值判断或已确认角色。

建议后续顺序：G0确认题意与需要先定的语义 → 在授权范围内只读数据审计并提出G1方案 → G1批准后按方案处理与核验 → G2确认数据版本 → 用户明确授权Q1 → 按A/B/C/D研究并由用户决定冻结与跨问 → Q2 → Q3 → Q4两分支。本轮不选择候选模型，也不启动上述后续工作。

### 14.1 问题三的任务，以及最后一句的含义

【题面明确】C题.pdf第2页问题3：0、6、12、18点获得未来24小时整点光伏功率预报；0点制定当天计划，其他预报时刻可以调整；存在调减、调增与五倍紧急购电费用。最后一句是“请分析是否需要引入其他时刻的预报制定调整购电策略”。

【上下文解释，提请确认】“其他时刻”指相对于零点的6、12、18点。应研究得到新信息后是否值得花调整费用修改订单，不要求凭空增加新的预报发布时间。制定调整策略也允许决定维持原订单。

现实矛盾是：多订电可能用不完，少订电可能被迫五倍补购；电池能缓冲一部分偏差，但受容量与功率限制。新预报若让我们发现原计划会留下较大缺口，提前加购可能划算；若偏差可由电池消化，改约可能没有收益。新预报也可能变差，不能先写“调整一定节省”。例如单价1元时，只有在确实需要额外20度且电池补不了等条件下，1.5倍提前增购的30元才可与5倍紧急补购的100元直接比较。

【拟采用的评价口径】相同零点附件3预报、负载预测、初态、设备、实际控制与费用口径下，比较三种信息/权限条件：①仅零点订电；②允许6/12/18点调整，但不读取这些时刻的新预报；③同样允许调整并读取新预报。①与③衡量整套日内机制，②与③分离新增预报信息的作用，①与②解释仅靠实际库存反馈及调整权限的作用。这是后续评价设计，不是本轮模型候选或已执行实验。各方案从同一起点出发，此后承接各自真实库存，不能每天强行拉齐。

### 14.2 附件3实物结构与10分钟转换建议

【附件观察】本轮重新只读打开附件3.xlsx：唯一Sheet1，1461行、26列；A1日期，B1预报时刻，C1:Z1为预报1—24小时。每天4行，共1460批、35040个功率值，单位kW。第一天B2:B5为0:00、6:00、12:00、18:00。结合题面整点含义和已有prepared-v1时间展开，6点C列对应当日7点，Z列对应次日6点；12点C列对应13点。不是6点这一行只描述6—7点一个小时。

【既有时间口径】内部按自然日d、区间k=1…144、Δt=1/6 h组织，区间起点00:00对应第一段，00:10对应第二段。原实际功率按起点值代表后继10分钟区间，保持Q1/Q2已有定义。本轮不改变真实日期、源值或原表。

【待确认，推荐】将同一发布版本的相邻整点预报连成直线，每隔10分钟读取一次功率，用该值代表后继10分钟，再乘1/6得到该段预测光伏电量。设两个相邻整点功率为F_h、F_(h+1)，则h点后第j个10分钟起点的功率为F_h+(j/6)(F_(h+1)−F_h)，j=0…5；电量为该功率/6。式中h是目标整点，不能误作发布时间。

说明例而非实际附件结果：同批预报10点600 kW、11点1200 kW，则10:00、10:10、10:20分别取600、700、800 kW，对应后继10分钟100、116.67、133.33 kWh。这样保留整点数值，又不假装掌握小时内真实云量变化。此处采用与现有实际序列一致的左端点分段近似，未采用梯形积分，也不能声称严格恢复该小时总发电量。整点值不是已知小时均值，不能直接套“小时电量守恒分配”。

【首小时缺锚与建议】每批从发布后1小时开始，缺发布时刻本身的点。例如12点新预报从13点起，不能直接用13点值冒充12点值。推荐在12点决策前，用刚结束的11:50—12:00区间光伏观测作为12点功率的近似锚点，再与新预报13点值连接。它是过去观测的短时延用，不是12:00—12:10的未来实际值；后者在零点式决策中不可提前读取。6点和18点同理，0点使用前日23:50区间。参考备选是沿用此前已发布版本对当前整点的预报；它不泄漏未来，但可能较旧。首版推荐观测锚点，后续如需检验小时拆分影响，再比较简单阶梯近似或另一合法锚点，不在本轮执行。

【边界】24点目标作为插值右端点，供生成23:50—24:00等末段；午夜边界本身不多算一个10分钟区间。日内发布预报跨入次日的部分保持真实日期，不裁成同日或重复计量。补间点只使用当次已发布的版本和当时已完成观测，不能将12点发布值回填6点的决定。prepared-v1中年末36个预报目标超出实际观测覆盖，保留为未来预报，不能冒充有实测标签或新增验证日。

【重要区别】上述换算得到的是预测光伏电量。result3要填的是综合负载、光伏、电池和价格后决定的外网购电量，不能把插值后的光伏数值直接抄进结果表。负载和光伏仍分开处理，历史10分钟负载参考无需为适配附件3先变成小时再拆回。
