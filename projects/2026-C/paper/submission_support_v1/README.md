# 参考文献核验与AI使用材料

## 文件用途

- `AI工具使用详情.pdf`：按用户提供的3页样例结构整理的3页报告，覆盖本项目当前可追溯的Codex使用。**全队外部AI工具/版本、立体图来源和人工终审范围尚待用户补充，当前不能标为已完成全队提交确认。** 文件不包含队员、学校或赛区信息，不复制模板中其他赛题或工具的事实。
- `AI工具使用详情.tex`：可编辑、可编译源文件。
- `AI工具使用声明.tex`：放置于最终论文参考文献之前的简短声明，与已记录的实际使用范围一致。未自动写入完整论文。
- `参考文献_核验版.pdf`：1页核验题录，9条均有真实来源；已补充DOI、在线书籍地址、政府文号和发布日。
- `参考文献_核验版.tex`：保留原9个引用键，按当前完整稿首次出现顺序排列。若团队把引用移到方法章节，应相应调整排序再编译。
- `参考文献核查报告.md`：内部逐条审查结论、证据链接、支持范围和使用建议，不是论文正文或AI提交材料。
- `sources/`：原网站/书目元数据和官方规范的内部核查留存，含用户样例的页面预览；不要将整个工作目录当作支撑材料直接打包。

## 复现

仓库根目录运行`python projects/2026-C/paper/submission_support_v1/build.py`，使用本机XeLaTeX和Poppler。PDF为A4，2.5cm页边距，黑色文字，页码居中。源文件可在确认事实后继续修订。
