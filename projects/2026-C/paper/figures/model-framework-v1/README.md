## 结构依据

来源为 `paper/complete_manuscript_v1/q1.tex` 至 `q4.tex`，并核对 Q4 report 第8.1及深化结论。正式状态保留旧Q1游标及未冻结事实，绘图依据用户本轮对已形成四问材料的明确授权；不进行研究阶段转换。

- 第一层：代表日曲线决定光伏直供后的缺口/富余，进入全时段电量流LP。约束框指向调度；输出144段购电、充放电及储电量。效率、容量、功率按既有口径。
- 第二层：零点历史分别预测负载/光伏，净需求历史误差确定近期加权准备，进入48小时LP，当天订单固定。真实供需与电池反馈决定实际紧急量及费用。
- 第三层：官方小时预报插值，按历史误差与同刻历史融合；负载预测继承第二问；动态准备进入滚动LP。最新真实库存和预报驱动未来订单调整，费用含普通/调整/紧急及期末余电价值。
- 第四层：两条并列的价格预测与调度组合。4-2继承Q2的供需和权限，4-3继承Q3的供需和权限；并非先执行4-2再执行4-3。
- 水平箭头表示信息转换、预测量或准备量进入调度、调度产生运行安排；向下箭头表示共享结构与新增条件，不表示前问订单锁定后问。Q1订单仅用于Q2首日启动，图内省略该边缘启动细节。
