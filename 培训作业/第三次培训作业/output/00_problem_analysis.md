# 问题分析与逻辑主线（2022 国赛 C 题）

## 题目要点
古代玻璃制品成分分析与鉴别。高钾玻璃与铅钡玻璃因助熔剂不同而成分不同；风化导致元素交换，干扰类型判断。成分性数据：有效样本成分和 ∈ [85%, 105%]。

## 小问拆解
| 小问 | 决策/输出 | 关键约束/难点 |
|---|---|---|
| Q1 | 风化与类型/纹饰/颜色关系；类型分层成分规律；风化前成分预测 | 小样本、空白=未检出、风化点/未风化点标注 |
| Q2 | 高钾/铅钡分类规律；类内亚类划分；合理性与敏感性 | 需要可解释规则 + 学习模型对照 |
| Q3 | 未知样本鉴别 + 敏感性 | 概率/稳定性，不能只给硬标签 |
| Q4 | 类内成分关联 + 类间关联差异 | 相关矩阵比较，不只均值比较 |

## 逻辑主线（非流水账）
**评价风化扭曲（Q1）→ 筛选分类规律并优化亚类（Q2）→ 分配到未知样本并量化不确定性（Q3）→ 比较关联结构解释工艺差异（Q4）→ 消融/灵敏度/鲁棒性闭环检验。**

## 主方案（国奖向）
1. Q1：χ²/Fisher + Cramer's V；Mann-Whitney；类型条件风化因子反演（对照：无校正、差值校正）
2. Q2：化学阈值规则 + 决策树/RF/SVM（LOO）；K-Means/层次聚类亚类（轮廓系数选K）；噪声与阈值灵敏度
3. Q3：RF主判定 + SVM/规则对照；5%噪声翻转率；训练LOO稳定性
4. Q4：Spearman + 显著网络；Mantel + |Δr|排序
5. 检验：特征消融、风化分层准确率、蒙特卡洛

## 风险点与升级
- 风化与类型混杂 → 全程类型分层 / 风化分层报告准确率
- 成分性和空白 → 有效区间过滤 + 缺失率可视化 + 0填充口径写清
- 小样本过拟合 → LOO / 规则对照 / 噪声鲁棒
- 统计口径：质量百分比；预测风化前成分归一化到100%

## 升级点（相对朴素baseline）
- 不只做列联表，还做风化因子反演与方法MAE对照
- 不只做聚类，还做可解释规则+多模型LOO+消融
- 不只给未知标签，还给置信度/翻转率/稳定性
- 不只两张热力图，还做Mantel与结构差排序
